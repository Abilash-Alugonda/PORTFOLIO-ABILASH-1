# Alugonda Abilash Reddy - Portfolio Project Folder

This folder contains the complete, standalone portfolio website for **Alugonda Abilash Reddy**.

```
portfolio/
├── index.html          # Main entry page (Tailwind CSS, Glassmorphism, Responsive)
├── assets/
│   └── profile.jpg     # Profile photograph
├── css/
│   └── style.css       # Custom styles, glows, animations, and glass effects
├── js/
│   └── script.js       # Navigation highlights, mobile toggle, clipboard copy
└── README.md           # Documentation and deployment guide
```

---

## 💻 How to Run Locally

### Option 1: Direct File Open
Double-click `index.html` to open directly in any browser (Chrome, Edge, Firefox, Brave).

### Option 2: Local Python Server
Open terminal in this `portfolio/` folder:
```powershell
python -m http.server 3000
```
Then visit: `http://localhost:3000`

---

## 🚀 Free 1-Click Deployment

### GitHub Pages:
1. Push this folder to a GitHub repository.
2. In your repo: **Settings** -> **Pages** -> Select **Branch: main**, folder **/ (root)**.
3. Click **Save** - your site will be live instantly!

### Vercel / Netlify:
- Simply drag-and-drop this `portfolio` folder directly into [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
